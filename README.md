# 🐍 Estudos de Python

Repositório criado para registrar minha evolução nos estudos de Python e Lógica de Programação.

## 📚 Curso

**Curso em Vídeo**

Este repositório reúne exercícios desenvolvidos durante meus estudos, com foco na prática e no desenvolvimento da lógica de programação.

## 🎯 Objetivo

Praticar lógica de programação, desenvolver minha base em Python e transformar os conceitos estudados em exercícios práticos.

## 📂 Estrutura

Os exercícios estão organizados na pasta `exercicios/`.

```text
exercicios/
├── ex001.py
├── ex002.py
├── ex003.py
├── ...
└── ex074.py
```

## ⭐ Exercícios de destaque

Alguns exercícios que representam conceitos importantes praticados
durante meus estudos de Python:

### 🤖 ex058 — Jogo de Adivinhação
Jogo de adivinhação utilizando números aleatórios, estruturas de
repetição, condicionais e controle de tentativas.

### 📱 ex059 — Calculadora com Menu
Calculadora interativa com diferentes operações matemáticas,
utilizando menus, estruturas de repetição e condicionais.

### 📊 ex065 — Análise de Números
Programa para receber diversos números e realizar análises como
média, maior e menor valor.

### 🛒 ex070 — Análise de Produtos
Programa que analisa produtos informados pelo usuário, calculando
o total gasto, identificando produtos acima de determinado valor
e encontrando o produto mais barato.

### 💰 ex071 — Sistema de Troco
Programa para calcular o troco e determinar a quantidade de
cédulas necessária para representá-lo.

> Este repositório continuará sendo atualizado conforme avanço nos estudos de Python.
